# 🍔 University Canteen Food App

A digital Food Ordering & Campus Canteen Management Application written in **Java** to streamline food selection, reduce queuing time, and manage daily canteen order queues.

## ✨ Key Features
- 📜 **Interactive Menu:** Browse categories (Breakfast, Snacks, Meals, Beverages) with live prices.
- 🛒 **Cart & Order Checkout:** Add items to cart, customize quantities, and place orders.
- ⏳ **Status Tracking:** Real-time order status updates (Preparing, Ready for Pickup).
- 🧑‍🍳 **Canteen Admin Portal:** Dashboard for canteen staff to update menu items and manage order fulfillment.

## 🛠️ Tech Stack
- **Language:** Java
- **UI / Platform:** Java Swing / Android SDK
- **Database:** SQLite / MySQL

## 🚀 How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/Bhavy3594/University-Canteen-Food-App.git
   ```
2. Open in your favorite IDE (Eclipse, IntelliJ IDEA, or Android Studio).
3. Build and Run the project launcher.
